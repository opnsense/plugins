# Bundled BIND 9.20.26 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` task-by-task.

**Goal:** Publish an OPNsense-ABI-specific BIND `9.20.26_1` replacement with `os-bind-rp`, so plugin installation installs a daemon containing ISC commit `fb0ae8a5d6b2abb8b6ad3529e205caacbe4e70d1`.

**Architecture:** CI builds `bind-tools` and `bind920` from a pinned FreeBSD Ports recipe after configuring each matching OPNsense repository. It installs those packages locally before packaging `os-bind-rp`, thereby recording a minimum compatible BIND dependency. The signed GitHub Release repository contains all three packages.

**Tech Stack:** FreeBSD Ports, OPNsense package repositories, FreeBSD `pkg`, shell, Python 3, GitHub Actions, GitHub Releases.

## Global Constraints

- BIND must be at least 9.20.26; the required ISC fix is absent in 9.20.24.
- Build separate packages for 26.1/FreeBSD 14.3 and 26.7/FreeBSD 15.1.
- Retain package names and origins `bind-tools`/`dns/bind-tools` and `bind920`/`dns/bind920`.
- Use custom package version `9.20.26_1`; official 9.20.27+ must supersede it.
- Pin and validate all source inputs. Do not use a FreeBSD binary package on OPNsense.
- Do not commit `tools/ci/tests/`; local test harnesses remain untracked.
